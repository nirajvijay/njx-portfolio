# Dr. Rohini's Dental Square — Redesign Concept

Standalone, independent redesign concept based on information published on the clinic's existing website. This is not the clinic's official website.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated hero artwork uses fictional people and is not presented as a real clinic photograph. Before any client delivery, the clinic should approve all business details, testimonials, treatment descriptions, contact information and imagery.
