# NJX Portfolio

The first build of Niraj V's personal portfolio: entrepreneur, systems builder, and lifelong learner.

It is a React/Vite site with responsive desktop and mobile layouts, selected work, a proof board, and direct contact links.

The repository also contains standalone local-business concepts. The Dr. Rohini's Dental Square project is built from `dr-rohini-dental-concept/` and published with the portfolio at `/dental-square/`.

## Run locally

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
```
